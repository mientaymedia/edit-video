# Font

Be Vietnam Pro — thiết kế bởi Be Team, phát hành theo **SIL Open Font License 1.1**.
Nguồn: https://fonts.google.com/specimen/Be+Vietnam+Pro

Chọn font này vì nó được thiết kế riêng cho tiếng Việt: dấu thanh đặt đúng chỗ và
không va vào dấu mũ ở cỡ chữ lớn — thứ mà phần lớn font Latin làm hỏng khi phóng to
trên video dọc.
